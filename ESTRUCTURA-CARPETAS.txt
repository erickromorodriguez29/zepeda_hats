========================================
COMO AGREGAR UN NUEVO PRODUCTO
========================================

1. Abre el archivo: js/products.js

2. Busca el array PRODUCTS y agrega un nuevo objeto asi:

{
    id: 19,                                    // Numero unico
    sku: "ZH-DANDY-008",                       // Codigo del producto
    name: "NOMBRE DE LA GORRA",                // Nombre
    description: "Descripcion del producto",   // Descripcion
    price: 1500,                               // Precio actual
    originalPrice: 1800,                       // Precio anterior (null si no hay)
    image: "images/products/dandy/nueva.jpg",  // Ruta de la imagen
    category: "dandy",                         // dandy, 31hats, barbas, otros
    isOffer: true,                             // true si esta en oferta
    isNew: false,                              // true si es nuevo
    isSold: false                              // true si esta vendido
}

3. Coloca la imagen en la carpeta correspondiente


========================================
COMO AGREGAR UN NUEVO VIDEO
========================================

1. Abre el archivo: js/products.js

2. Busca el array VIDEOS y agrega:

{
    id: 7,
    title: "Titulo del Video",
    thumbnail: "images/videos/thumbnails/video-7.jpg",
    video: "videos/video-7.mp4"
}

3. Coloca el video .mp4 en /videos/
4. Coloca la miniatura .jpg en /images/videos/thumbnails/

========================================
SUBIR A GITHUB PAGES
========================================

1. Crea un repositorio en GitHub
2. Sube todos los archivos
3. Ve a Settings > Pages
4. Selecciona la rama "main" y carpeta "/ (root)"
5. Tu sitio estara en: https://tuusuario.github.io/nombre-repo/
